IMPORTANTE PARA JAVA SWING:
- Font.createFont puede cargar archivos TTF desde el classpath con getResourceAsStream.
- ImageIcon carga PNG/JPG, pero NO renderiza SVG de forma nativa.
- Hay que convertir SVG a PNG o usar un renderizador SVG antes de mostrarlos.
- Al compilar con javac, los recursos NO se copian automaticamente a out/.
- El instalador no modifica ni reemplaza codigo Java.
